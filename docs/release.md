# Передача прототипа — `prototype-v1`

Версия `0.1.0` (`versionCode = 1`), пакет `com.pricelens`, `minSdk 26`, `targetSdk 35`.
Сборка **debug**, без подписи для публикации. Тег `prototype-v1` указывает на коммит передачи.

## Что собрано

```powershell
.\gradlew.bat :app:assembleDebug
```

APK: `app\build\outputs\apk\debug\app-debug.apk` (не хранится в Git, пересобирается командой выше).

- Размер: 56 667 129 байт (~54 МиБ) — в APK включена модель OCR ML Kit, загрузка по сети не нужна.
- SHA-256: `1A0DF86C054BEBD91B52EAEB6A338BF678B88745349203B7C2515F76FDCAC51E`.
- Установка: `adb install -r app\build\outputs\apk\debug\app-debug.apk`.

Хэш относится к сборке в среде разработки; после пересборки APK меняется, поэтому перед передачей
APK-файла стоит перепроверить контрольную сумму.

## Что работает

- Съёмка ценника камерой и распознавание текста **на устройстве** (bundled ML Kit, без загрузки модели
  через Play Services); распознанные поля можно исправить вручную до сравнения.
- Парсер ценников и расчёт цены за 1 кг / 1 л; сравнение **до 5 товаров** на одном экране,
  подсветка самой выгодной позиции и разницы с ней.
- Текущая выборка сохраняется между запусками (Room/DataStore), все данные остаются в `$applicationId`.
- Полностью офлайн: `INTERNET` и `ACCESS_NETWORK_STATE` принудительно удалены из итогового манифеста
  (иначе их добавляет транзитивная библиотека datatransport bundled ML Kit); собственной аналитики,
  crash-репортеров, remote config и синхронизации нет.
- Отказ в доступе к камере даёт понятное сообщение с подсказкой, где включить разрешение;
  после возврата из настроек доступ перепроверяется.
- Облачный бекап и device-transfer запрещены, есть адаптивная иконка приложения.

## Что не проверено

- Работа на физическом устройстве в режиме полёта: в среде разработки нет устройства и эмулятора.
  Чек-лист ручной проверки приведён в README — это один из обязательных ручных шагов приёмки
  наряду с проверкой камеры и качества OCR на реальных ценниках.
- `connectedAndroidTest` не запускался: Compose UI-тесты и тесты DAO только скомпилированы.
- Реальное качество OCR на разных ценниках и поведение камеры на разных устройствах.

## Известные ограничения

- Мелкий или размытый текст ценников распознаётся хуже — поля можно поправить вручную.
- Модель OCR включена в APK, поэтому сборка тяжёлая (~54 МиБ). Вместе с ML Kit в APK попадают
  служебные классы datatransport; сетевые разрешения для них удалены, поэтому передача данных
  по сети невозможна.
- История сравнений и категории не входят в прототип.
- Сборка debug и без подписи: для публикации понадобится release-конфигурация и ключ подписи.

## Бэклог (после передачи)

1. История сравнений (схема БД уже проектируется с расчётом на неё).
2. Категории товаров и фильтры внутри сравнения.
3. Улучшение парсера под мелкие и нестандартные ценники, метрики качества на реальных фото.
4. Инструментальный прогон на устройстве: режим полёта, камера, сохранение между запусками.
5. Release-сборка с подписью и подготовка к распространению.
