# PriceLens

Offline-first Android-приложение: фотографируешь ценник, приложение распознаёт вес/объём и цену,
считает стоимость за 1 кг или 1 л и позволяет сравнить до 5 товаров на одном экране.

Без авторизации, без сервера, без доступа к интернету — все данные остаются на телефоне.

Готовые APK для установки — на странице [Releases](https://github.com/Gnum127/pricelens/releases)
(она доступна и из главной страницы репозитория через вкладку **Releases** справа).

## Статус

Прототип готов: один экран сравнения до 5 товаров, съёмка ценника камерой с on-device OCR,
ручная корректировка полей до сравнения и сохранение текущей выборки между запусками.
Все этапы плана закрыты, прототип передан как `prototype-v1`; детали — в [docs/release.md](docs/release.md).

## Сборка

Нужны JDK 17 и Android SDK с установленным `compileSdk 35`. Из корня репозитория в PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug
```

APK появится по пути `app\build\outputs\apk\debug\app-debug.apk`. Установка на устройство:

```powershell
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

Локальные проверки (без устройства):

```powershell
.\gradlew.bat test lint
```

## Проверка офлайна на устройстве

1. Включите **режим полёта** и отключите Wi‑Fi — доступ к сети полностью отсутствует.
2. Откройте приложение: экран сравнения должен загрузиться, а сохранённые товары — восстановиться.
3. Нажмите «Добавить товар», разрешите доступ к камере и сфотографируйте ценник.
   При отказе в разрешении появится сообщение с подсказкой, где включить доступ.
4. Добавьте 5 товаров, при необходимости поправьте название, вес/объём и цену.
   Самая выгодная позиция подсвечена, разница с ней показана в остальных карточках.
5. Закройте и заново откройте приложение — выборка из 5 товаров должна сохраниться.
6. Убедитесь, что сети нет: в итоговом манифесте APK нет `INTERNET` и `ACCESS_NETWORK_STATE`
   (проверяется через `adb shell dumpsys package com.pricelens`), модель OCR включена в APK,
   данные хранятся только в Room/DataStore. Сетевые разрешения принудительно удалены при слиянии
   манифеста, потому что их добавляет транзитивная библиотека bundled ML Kit. В настройках Android
   отображается только разрешение «Камера» — INTERNET не является runtime-разрешением.

## Известные ограничения

- Мелкий или размытый текст ценника распознаётся хуже — поля можно исправить вручную.
- История сравнений и категории не входят в прототип (бэклог после передачи).
- Инструментальные тесты камеры и Room требуют устройство или эмулятор.
- Проверка в режиме полёта на физическом устройстве в среде разработки не выполнялась:
  устройства и эмулятора нет. Чек-лист выше — инструкция для ручной проверки на устройстве.
- В среде разработки с падающим Kotlin daemon сборку нужно догонять флагом
  `-Pkotlin.compiler.execution.strategy=in-process`, например:
  `.\gradlew.bat :app:assembleDebug -Pkotlin.compiler.execution.strategy=in-process`.
  На обычной машине флаг не нужен.
